# UI Consistency Verification Checklist

## Light Mode

- [x] Every list page (Ideas, Projects, Workbox, Flows,
      Teams, Users, Activity Feed, Snapshots) has
      identical page header styling
- [x] Description text is consistently smaller (text-sm)
      across all pages
- [x] All dialogs (New Work Order, Import Flow,
      Add Team Member, Confirm Action) use the same
      header/footer pattern
- [x] Badges and pills have uniform padding
- [x] Sidebar nav items have consistent padding
- [x] Dashboard action cards grid spacing matches
      other card grids

## Dark Mode (toggle theme)

- [x] Cards have visible borders
- [x] Flow designer toolbar/canvas/panels have proper
      dark backgrounds
- [x] Table rows have subtle hover highlighting
- [x] Tooltips are inverted (light on dark)
- [x] Badges have visible borders
- [x] Hero button glow is softer
- [x] Dropdowns have elevated appearance with shadow

## Keyboard Focus (Tab through elements)

- [x] Dropdown items show blue focus ring
- [x] Command palette (Cmd+K) selected item shows
      consistent ring
- [x] Buttons and inputs all show focus indicators
